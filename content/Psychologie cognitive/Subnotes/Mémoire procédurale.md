# Mémoire procédurale - Expression Anoétique

Elle permet de maintenir nos apprentissages, typiquement moteur (marcher, faire du vélo, ...). Il n'y a pas besoin de quelque niveau de conscience pour accéder à cet mémoire (= expression de mémoire *anoétique*, sans conscience).    

Les seules description que nous ayons de la mémoire procédurale sont des description behaviouriste, on ne sait pas expliquer (créer de modèle de) ce type de mémoire expérimentalement.
